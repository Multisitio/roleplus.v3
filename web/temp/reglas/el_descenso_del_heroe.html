El descenso del héroe

Una adaptación para jugar a HeroQuest con los dados y la intensidad de Descent, uniendo la exploración clásica con un combate táctico y dinámico.

Dados de ataque

Obligatorios en cada asalto, definen la naturaleza y el tipo del ataque realizado.

  • Rojo: Para el choque del acero en el combate cuerpo a cuerpo.
  • Azul: Para la tensión del arco o proyectiles en el combate a distancia.
  • Blanco: Para el canalizar arcano en el combate mágico.

Dados adicionales

Modificadores que alteran y potencian el impacto del ataque.

  • Amarillos (Equipo): Dados otorgados por la calidad de las armas, escudos y equipo táctico. Destacan por su abundancia de incrementos, facilitando la activación de efectos especiales.
  • Negros (Esfuerzo): Dados de potencia destructiva y fuerza bruta. Están reservados exclusivamente para la mecánica de esfuerzo.

El Dado Verde: Destreza, Apoyo y Defensa

El dado verde queda descartado de las armas y se utiliza para las siguientes mecánicas especiales:

  • Apoyo y Flanqueo (Sinergia): Si un héroe ataca a un enemigo que está adyacente a otro héroe aliado (que no esté incapacitado), añade un dado verde a su tirada de ataque por la distracción táctica generada.
  • Destreza y Exploración: Se lanza para resolver pruebas físicas del escenario ajenas al combate directo (saltar fosos, esquivar trampas que se activan repentinamente, forzar cerraduras o moverse en sigilo).
  • Defensa Ligera (Esquiva): Los héroes que no vistan armadura pesada pueden añadir un dado verde a su reserva de defensa. Un incremento en este dado permite esquivar completamente el ataque o realizar un contraataque inmediato si el héroe posee esa habilidad.

Caras de los dados

  • N: Suma al alcance máximo. Fundamental para impactar a distancia.
  • C: Suma al daño infligido. Son las heridas que sufre el enemigo.
  • I: Suma a los incrementos. Poder puro para activar habilidades o potenciar ataques.
  • V: Cara vacía. Sin efecto adicional, pero segura frente a maldiciones.
  • X: Fracaso absoluto. El ataque se pierde sin remedio.

Fracaso y Defensa

Fracaso: Todo ataque falla de inmediato si un dado muestra la temida X, o si la suma del alcance no llega hasta la miniatura objetivo en ataques a distancia.

Defensa: La resistencia se mide con los dados blancos originales de HeroQuest. Cada escudo obtenido (blanco para héroes, negro para monstruos) bloquea y anula un daño del ataque enemigo.

Armería y Equipo

La conversión de las armas de HeroQuest sigue un patrón directo y universal, eliminando la necesidad de traducir cada pieza una a una:

  • Ataque Base (1 Dado): Determinado por el tipo de ataque (Rojo para cuerpo a cuerpo, Azul para distancia, Blanco para magia).
  • Modificador de Equipo (Dados Amarillos): Se añaden dados amarillos equivalentes al número de dados de combate del arma original de HeroQuest menos uno ($N-1$).

Incrementos y Esfuerzo

Esfuerzo: Los héroes pueden agotar su vitalidad bajo presión. Por cada punto de Mente o Cuerpo sacrificado voluntariamente antes de realizar la tirada, el héroe añade un Dado Negro al ataque. Este es el único método para obtener dados negros en juego.

Héroes: Pueden gastar los incrementos obtenidos para sumar daño extra (1 incremento = +1 Daño), aumentar el alcance (1 incremento = +1 Alcance) o activar capacidades únicas de sus armas y hechizos.

El Guardián: Por cada 2 incrementos obtenidos por un monstruo, o desperdiciados por un héroe, el Guardián gana una ficha de amenaza para activar trampas o potenciar futuras emboscadas.
